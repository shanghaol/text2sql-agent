## 紧凑版（简历用）

**Text-to-SQL 智能数据分析助手**（Python / LangChain v1 / DeepSeek / Spring Boot 3 / Vue3 / MySQL 8）—— 主导设计与 AI 协作开发，已上线 [sql.shanghl.club]（29 天，约 60 commits）

- 设计"Java 工程化 + Python 大脑"双服务架构（网关鉴权/限流/审计与 Agent 检索/推理分离），实现四层 SQL 安全防线：DB 只读账号、会话级只读、**sqlglot AST 语义白名单**（替换正则，消除字面量误杀与子查询漏判）、服务端执行超时；另支持 LangGraph 原生中断的 SQL 执行前人工审批（HITL）
- 实现混合检索 RAG：三路语料（表结构/业务口径/用户反馈自举 few-shot）+ BM25/向量双路（自实现 RRF 融合）；建立语料质量门（六道门槛 + 文本/语义双层去重），点赞样本人工审核后入库形成自进化闭环
- **自建 50 条评测集**（五类题型 + 示例/近例/远例三层分层），以 9 组单变量消融（1274 次运行，语料冻结 + 预注册纪律）量化各组件贡献：**RAG 整体 +12.7pp**（14.0%→26.7%）、**few-shot 为最大单项**（去除 −16.7pp，示例层 52%→9%）、**bge-reranker 双轮消融证实净负**（−4.0pp）且归因至重排顺序扰动（纯顺序对照 −6.0pp）——负结果未上线，配额代码留档
- 实现 BYOK 用户自带 LLM Key 全链路：AES-256-GCM 加密落库、免费幂等校验、指纹脱敏（日志 grep "sk-" 恒为 0）、服务端结构性不留站点级 Key；SQL 结果双层指标（SQL 级 + 答案级，Agent 文本计算兜底单独计量）
- 生产部署：2C2G 单机原生共存（systemd 双服务内存封顶 + nginx SSE 反代 + 证书自动续期），六轮独立代码审查（密钥泄漏面穷举、对抗 SQL 40 组、限流绕过实测复现），全部 P1 生产验证修复

## 展开版（个人网站 / 详细版简历 / 面试自我介绍底稿）

**背景与定位**：2026-10-08 → 11-03（27 天），为 12 月实习投递构建的求职项目。设计目标是三层：上线的可用系统、量化的实验结论、可深挖的工程方法论。

**核心架构决策**（每条都经过 AI 产出选项 → 我拍板的流程）：
1. 双服务分工：Java 承担鉴权/限流/审计/BYOK 密钥管理（工程层），Python 承担检索/推理（AI 层），SSE 头透传连接
2. BYOK（用户自带 Key）：服务端结构性不留站点级 Key——AES-256-GCM 落库 + 主密钥环境注入 + 指纹脱敏；LLM 成本由用户自担
3. 职责边界原则："读路径、判断密集的给模型；写路径、确定性副作用、安全边界的不给模型"——查询历史落库走网关后处理而非模型工具，避免审计依赖被审计者
4. 检索：混合检索三路语料 + RRF 融合；检索层实验先离线标定（确定性选片函数可零成本穷举变体）、LLM 只验证最优

**实验与数字**（详见 experiment-log W3/W6/W7 段）：
- 判定体系：执行准确率（金标/模型 SQL 都真库重放、比较结果集）+ 答案级（Agent"SQL 取数+文本计算"两步作答单独计量）；判定逻辑变更离线复判历史数据（132 次零翻转）
- 消融结论（9 行 OAT，1274 次运行）：RAG +12.7pp（~2.5σ）；few-shot −16.7pp（>3σ，最大单项）；RRF k 调优 +4.6pp（1σ 内，措辞降格为方向性观察）；bge-reranker 双轮负结果（顺序扰动 −6.0pp 独立成立）——负结果未上线，归因与代码留档
- 分层发现：few-shot 示例层（有同款示例的题）52% vs 远例层 24.6%——45pp 断层指向自举与泛化的优化方向

**工程素养证据**：
- 六轮独立代码审查：BYOK 密钥泄漏面穷举（grep sk- 恒 0）、对抗 SQL 40 组全拦、限流绕过实测复现后修复生产验证、1274 条消融记录独立复算零翻转
- 排障实录四段（全部有根因链）：JDK HttpClient h2c 升级头被 uvicorn 拒、fastembed 模型缓存 %TEMP% 陷阱、env 变量名跨服务冲突、Pinia 响应性丢失致流式不渲染
- 预注册纪律：消融/修复实验跑前冻结预期与分支树；预注册被自家数据修正两次（机制假说、主案选片）全部留痕——"对自家归因保持怀疑"

**明确不做的克制**（面试答"为什么不用 X"）：微调/本地部署 LLM、多 Agent 产品架构（单 Agent+多工具符合官方判断三问）、多租户、MCP Server（与 HITL 安全叙事冲突）、ECharts（门面非区分项，重估触发条件已备）。
